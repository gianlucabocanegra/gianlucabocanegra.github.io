I made an Arduino program that makes the vibe board buzz in Morse code. When the alligator clip doesn't touch each other, it buzzes my name. When they touch, it buzzes SOS.

I made one function for my name and one for SOS. Each letter has its own small function too and every letter is built from two tiny functions, one for a dot and one for a dash.

I also did the extra credit. The program switches between my name and SOS right away instead of waiting for the message to finish.

Here is a photo:

![Kit setup](/assets/img/help-setup.jpg)

**Tip for past me:** Build the dot and dash functions first, then make the letters, then make your name. And don't use one long delay. Wait in tiny steps and check the switch each time.
