For this homework, I made an Arduino program where three sets of LEDs blink like fireflies all at the same time. Each set has its own blinking pattern. Before this I had written each pattern in a separate program. This time I put all three into one file so they run together.

Here is a photo of my LEDs on:

![Fireflies LEDs](/assets/img/fireflies.jpeg)

**Tip for past me:** Before you write any code think about which things the fireflies share and which things each one needs on its own. They all use the same timer but each firefly needs its own state. Planning this on paper first would have saved me a lot of confusion. Very interesting homework, I enjoyed it overall.
